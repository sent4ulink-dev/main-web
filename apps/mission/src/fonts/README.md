# Licensed fonts

Drop a **licensed** web-font file of *Lumios Typewriter Old* here (e.g. `lumios-typewriter-old.woff2`; any file
whose name contains "lumios" is picked up). The letter, the envelope and its edit layer then use it automatically.

Lumios Typewriter is a commercial font by My Creative Land. Use a licence that covers self-hosted web use
(webfont / self-hosted licence from the foundry or a reseller). Do not use "free for personal use" copies.
Until a file is here, the letter uses Cousine (Apache 2.0) as the typewriter face.
